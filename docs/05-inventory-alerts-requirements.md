# 재고 부족/소진 알림 요구사항

> 목적: 재고 업로드 이후 매장 직원과 본사가 부족/소진 상품을 즉시 확인하고, 다음 발주 업무로 이어질 수 있게 한다.

---

## 1. 문제 정의

현재 재고 화면은 수량 조회와 조정은 가능하지만, 부족/소진 판단 기준이 화면마다 다르다.

- 재고 목록은 `quantity <= 0`만 일부 강조한다.
- 홈 대시보드는 임시로 `quantity <= 5`를 부족 기준으로 쓴다.
- 실제 업무 기준인 `minQuantity`가 재고 API 응답에 없다.
- 부족/소진 항목을 목록 상단으로 올리는 정렬이 없다.
- 서버에서 재고 부족 알림을 자동 생성하지 않는다.

---

## 2. 핵심 정책

| 상태 | 조건 | 표시 |
|------|------|------|
| 소진 | `quantity === 0` | danger 뱃지 |
| 부족 | `quantity > 0 && quantity < minQuantity` | warning 뱃지 |
| 정상 | `quantity >= minQuantity` | 기본 표시 |

`minQuantity`는 상품별 최소 보유 수량이다. 초기값은 5로 둘 수 있지만, 서버에 저장되는 값이어야 한다.

---

## 3. 사용자 흐름

1. 사용자가 재고 화면에 진입한다.
2. 소진/부족 상품이 목록 상단에 먼저 보인다.
3. 상품 카드에 `소진` 또는 `부족` 뱃지가 표시된다.
4. 사용자는 부족 상품을 눌러 상세 정보 또는 발주 화면으로 이동할 수 있다.
5. 재고 업로드 또는 수량 조정 후 상태가 바뀌면 알림 대상이 갱신된다.

---

## 4. 서버 요구사항

### 4.1 InventoryItem 필드

| 필드 | 타입 | 설명 |
|------|------|------|
| minQuantity | Integer | 최소 보유 수량. 기본값 5 |
| stockStatus | Enum 또는 응답 계산값 | OUT_OF_STOCK / LOW / SUFFICIENT |

### 4.2 API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/api/inventories` | `minQuantity`, `stockStatus` 포함 |
| PATCH | `/api/inventories/{id}/min-quantity` | 최소 보유 수량 수정 |
| GET | `/api/inventories/alerts` | 부족/소진 재고만 조회 |

### 4.3 정렬

부족/소진 조회에서는 아래 순서를 기본으로 한다.

1. 소진
2. 부족
3. 수량 낮은 순
4. 최근 수정 순

### 4.4 알림 생성

재고 업로드 또는 수량 조정 후 아래 조건을 만족하면 `NotificationType.INVENTORY_LOW` 알림을 생성한다.

- 정상에서 부족 또는 소진으로 변경됨
- 부족에서 소진으로 변경됨

같은 상품에 대해 중복 알림이 너무 자주 쌓이지 않도록 하루 단위 중복 방지를 둔다.

---

## 5. 앱 요구사항

### 5.1 재고 목록

- 부족/소진 항목을 상단 정렬한다.
- 상품 카드에 `소진`, `부족` 뱃지를 표시한다.
- 수량 영역은 상태별 색상을 적용한다.
- `부족/소진만 보기` 필터를 제공한다.

### 5.2 홈 대시보드

- 임시 기준 `quantity <= 5`를 제거한다.
- 서버 응답의 `stockStatus` 또는 `minQuantity` 기준으로 표시한다.
- `CRITICAL`, `LOW` 카운트를 실제 상태 기준으로 계산한다.

### 5.3 추후 발주 연결

- 부족/소진 카드에 `발주` 액션을 연결할 수 있게 항목 ID, 상품명, 현재 수량, 최소 수량, 권장 발주 수량을 보관한다.

---

## 6. 완료 기준

- `quantity === 0`이면 항상 `소진`으로 표시된다.
- `quantity < minQuantity`이면 항상 `부족`으로 표시된다.
- 홈과 재고 목록이 같은 기준을 사용한다.
- 부족/소진 항목이 재고 목록 상단에 정렬된다.
- 서버 테스트에서 상태 계산과 알림 생성 조건을 검증한다.
- 클라이언트 테스트에서 뱃지/정렬/필터가 검증된다.
